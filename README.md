# Y4NGZ Media

Public media assets used by Y4NGZ Thunderstore mod listings.

## LethalCCTV

The `lethalcctv/` directory contains web-optimized gameplay GIFs for the
LethalCCTV package README. These files are listing media only and are not
required by the mod at runtime.

## Anomalies

The `anomalies/` directory contains the public creature previews used by the
Anomalies Thunderstore README. These files are listing media only and are not
